=== ΟΔΗΓΙΕΣ ΕΓΚΑΤΑΣΤΑΣΗΣ ===

1. ΚΛΩΝΟΠΟΙΗΣΗ REPOSITORY:
   git clone https://github.com/ChrysKoubanis/E-shop

2. ΔΗΜΙΟΥΡΓΙΑ VENV:
   Στο console ,γραψτε: python -m venv venv

3. ΕΝΕΡΓΟΠΟΙΗΣΗ VENV:
   Στο console ,γραψτε: Για Windows: venv\Scripts\activate
   Στο console ,γραψτε: Για macOS/Linux: source venv/bin/activate

4. ΕΓΚΑΤΑΣΤΑΣΗ BIBLIOTHIKΩΝ:
   Στο console ,γραψτε: pip install -r requirements.txt

5. ΡΥΘΜΙΣΗ VS CODE:
   - Ανοίξτε το VS Code και πατήστε Ctrl+Shift+P
   - Επιλέξτε "Python: Select Interpreter"
   - Enter Interpreter path
   - Find
   - Διαλέξτε το Python.exe από το venv/Scripts (E-shop/venv/Scripts/python.exe)

6. ΕΚΤΕΛΕΣΗ:
   python app.py
